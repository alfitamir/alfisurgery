# APPENDIX E — SBAR HANDOVER TEMPLATES

## E.1 Suspected perianal abscess

|                            | Suggested wording                                                                                                        |
| -------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| S                          | “I am calling about [patient], [age], with [x] days of worsening perianal pain.”                                         |
| B                          | “[Diabetes / immunosuppression / previous abscess]. No drainage yet.”                                                    |
| A                          | “Temperature [x] °C, HR [x]; tender red induration at the [quadrant] perianal margin; cannot sit.”                       |
| R                          | “Please review within [1–2] hours for same-day drainage.”                                                                |
| 🚨 Escalate immediately if | Temperature above 38.0 °C with HR > 110/min, spreading redness, skin discoloration, crepitus, or systolic BP ≤ 100 mmHg. |

## E.2 Suspected Fournier’s gangrene

|                            | Suggested wording                                                                                                                         |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| S                          | “I am concerned this patient has Fournier’s gangrene.”                                                                                    |
| B                          | “[Age]; diabetic on [SGLT2 inhibitor]; perineal pain for [x] hours.”                                                                      |
| A                          | “Pain out of proportion; [dusky skin / crepitus]; HR [x], BP [x], lactate [x]. Redness has spread beyond the marked line in [x] minutes.” |
| R                          | “Please attend **now** and inform theatre; I am starting the sepsis bundle.”                                                              |
| 🚨 Escalate immediately if | Any crepitus, hypotension, confusion, or spread beyond the marked border.                                                                 |

## E.3 Post-banding pelvic sepsis

|                            | Suggested wording                                                                                               |
| -------------------------- | --------------------------------------------------------------------------------------------------------------- |
| S                          | “[Patient] had banding [x] days ago and has worsening pain, fever, and difficulty passing urine.”               |
| B                          | “Banding on [date]; [antithrombotics].”                                                                         |
| A                          | “Temperature [x] °C, HR [x], BP [x]; bladder scan [x] mL.”                                                      |
| R                          | “Please review **immediately** — I suspect pelvic sepsis; cultures taken, antibiotics prescribed per protocol.” |
| 🚨 Escalate immediately if | Any combination of worsening pain, temperature above 38.0 °C, and urinary difficulty.                           |

## E.4 Delayed post-banding haemorrhage

|                            | Suggested wording                                                                    |
| -------------------------- | ------------------------------------------------------------------------------------ |
| S                          | “[Patient], [x] days after banding, is passing fresh blood and clots.”               |
| B                          | “Banding on [date]; restarted [anticoagulant/antiplatelet] on [date].”               |
| A                          | “[x] pads in [x] hours; HR [x], BP [x]; Hb [x] (baseline [x]).”                      |
| R                          | “Please review within 15–30 minutes; FBC, coagulation, and crossmatch sent.”         |
| 🚨 Escalate immediately if | HR > 110/min, systolic BP < 100 mmHg, more than 1 pad per hour, or Hb fall ≥ 20 g/L. |

## E.5 Rectal prolapse requiring reduction

|                            | Suggested wording                                                               |
| -------------------------- | ------------------------------------------------------------------------------- |
| S                          | “[Patient] has a prolapsed rectum that has not reduced.”                        |
| B                          | “Out for [x] hours; previous episodes [yes/no].”                                |

| R                          | “Please review within [30–60] minutes; analgesia given; sugar ready if viable.” |
| 🚨 Escalate immediately if | Dusky, grey, or black mucosa; peritonism; failed reduction.                     |
